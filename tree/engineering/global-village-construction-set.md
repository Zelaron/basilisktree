Publish open-source designs for the 50 industrial machines a small community needs to sustain modern life, from a tractor and a brick press to a 3D printer, so that anyone can build them from the documentation, as Marcin Jakubowski of Open Source Ecology set out in a 2011 TED talk. By 2014 12 machines had been prototyped, and OSE reported a third of the set done in 2018. Solving it means all 50 built and replicated by others.
