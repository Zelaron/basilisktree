Fujio Masuoka at Toshiba invented flash memory, presented in 1984, a non-volatile memory that can be erased in blocks and keeps its data without power. NAND flash followed in 1987, and flash memory now stores data in phones, cameras, USB sticks and solid-state drives, and has largely replaced the hard disk in laptops.
