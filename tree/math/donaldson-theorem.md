Using moduli spaces of Yang–Mills instantons, Donaldson showed in 1983 that a closed smooth simply connected 4-manifold with definite intersection form must have the diagonal form, so many topological 4-manifolds admit no smooth structure. With Freedman's work this gave exotic ℝ⁴.
