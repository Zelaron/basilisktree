Richard Hamming, frustrated when weekend jobs on Bell Labs' relay computers aborted on single errors, devised codes that locate and correct one flipped bit (published 1950). Hamming distance became the basic measure of how well a code resists errors, and Hamming-style codes still protect computer memory.
