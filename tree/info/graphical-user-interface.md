Xerox PARC's Alto (1973), designed by Chuck Thacker and Butler Lampson with Alan Kay's vision of personal computing, had a bitmapped display, overlapping windows, icons, menus and a mouse. Xerox's Star (1981), Apple's Lisa (1983) and Macintosh (1984) and Microsoft Windows carried the interface to the public.
