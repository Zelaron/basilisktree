IBM's System/360 (announced 1964), designed by Gene Amdahl, Fred Brooks and Gerrit Blaauw, defined one instruction set for a whole family of machines at different prices, so that software ran on all of them. It separated architecture from implementation and standardized the 8-bit byte.
