OpenAI's Codex (Chen and colleagues, 2021), a GPT model fine-tuned on public code, powered GitHub Copilot, which completed code from comments and context from June 2021. DeepMind's AlphaCode (2022) reached roughly the median level of human participants in Codeforces programming contests.
