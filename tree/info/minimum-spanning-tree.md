Otakar Borůvka (1926) found the cheapest way to connect a set of towns into one electrical network, the first minimum-spanning-tree algorithm. Jarník (1930), Kruskal (1956) and Prim (1957) found the algorithms taught today. The problem arises in network design, clustering and approximations of the travelling salesman problem.
