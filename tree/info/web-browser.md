NCSA Mosaic (1993), written by Marc Andreessen and Eric Bina, displayed images inline with text, ran on ordinary Unix, Windows and Macintosh computers, and had a simple point-and-click interface. Netscape Navigator (1994) followed, and use of the Web grew very quickly.
