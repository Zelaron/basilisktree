Coding agents combine a language model with tools to read and edit a code repository, run tests and iterate. SWE-bench (2023) measured them on real GitHub issues, SWE-agent and Devin (2024) and then Claude Code and OpenAI Codex (2025) were released as products, and METR (March 2025) found that the task length frontier agents complete had doubled about every seven months since 2019.
