Edgar Codd's 1970 paper proposed storing data as relations, tables manipulated by a declarative algebra, so that programs need not know how the data is laid out. SQL (1974) and Oracle (1979) turned the model into the dominant database technology, and Codd received the 1981 Turing Award.
