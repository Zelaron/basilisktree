Alonzo Church's calculus of functions (developed 1932 to 1936) computes by substituting arguments into function bodies. He used it in 1936 to show that Hilbert's Entscheidungsproblem is unsolvable, and it defines the same computable functions as Turing machines. It underlies functional programming languages and type theory.
