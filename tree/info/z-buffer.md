Edwin Catmull's 1974 Utah thesis introduced the Z-buffer, which stores a depth value for each pixel so that the nearest surface is drawn, and texture mapping, which wraps images onto surfaces. Wolfgang Straßer described depth buffering in his own thesis the same year. Every GPU performs both operations, and Catmull shared the 2019 Turing Award.
