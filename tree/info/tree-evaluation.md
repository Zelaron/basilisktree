James Cook and Ian Mertz (2023) showed that the tree evaluation problem can be solved in O(log n log log n) space, improving the earlier O(log² n / log log n) and using ideas from catalytic computing. It undercut the plan of using tree evaluation to separate L from P, and it led to Ryan Williams's 2025 result.
