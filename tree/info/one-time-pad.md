Gilbert Vernam's teleprinter cipher (1917) combined each character of a message with a character from a punched key tape. With Joseph Mauborgne's addition of a truly random key used only once, it cannot be broken, as Claude Shannon proved in 1949. Frank Miller had described the same idea in 1882.
