Shunyu Yao and colleagues' ReAct (2022) prompted language models to alternate between reasoning steps and actions such as searching, and Timo Schick and colleagues' Toolformer (2023) taught models to decide when to call external tools. This loop, in which a model acts step by step and reads the results, underlies assistants that browse, run code and operate software.
