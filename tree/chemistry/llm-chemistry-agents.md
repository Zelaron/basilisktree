Coscientist (Daniil Boiko, Gabe Gomes and colleagues, Nature, 2023) and ChemCrow (Andres Bran, Philippe Schwaller and colleagues, 2023 to 2024) gave GPT-4 access to tools such as web search, code and laboratory automation. They planned and ran real experiments, including palladium cross-couplings on an automated platform.
