Build a machine that takes the structure of any reasonable small organic molecule and, with no human help, plans a route, runs the reactions, purifies the product and confirms its identity. Burke's iterative coupling machine (2015) and AI-planned robots since 2019 handle only restricted reaction types or still need chemists at key steps. A solution is an open system that makes most of a blind set of diverse drug-like targets this way.
