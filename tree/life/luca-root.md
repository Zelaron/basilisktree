Where does the universal tree take root, and what did the last universal common ancestor have? Every possible outgroup sits inside the tree, so since 1989 the root has been inferred from genes that duplicated before that ancestor. A solution is a root and an ancestral gene set that survive models accounting for horizontal transfer, compositional bias and long branches.
